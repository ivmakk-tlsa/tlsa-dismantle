# Images

Nexus page images, tracked in the repo. The background is 1300x372, the gallery images are 1920x1080. The mods-grid thumbnail is not a separate file: Nexus picks it from the uploaded gallery images.

Dismantle's effect is inventory-based, not a screen effect, so the gallery shots are staged around a dispose.

- `banner.jpg` - the mod page background image (1300x372).
- `01-tlsa_dismantle_thumb.jpg` - hero shot: an inventory with the salvage just added and the game's "added to inventory" popup. Pick this as the mods-grid thumbnail.
- `02-tlsa_dismantle_weapon.jpg` - before/after: a spare ranged weapon disposed, scrap or firearm parts returned.
- `03-tlsa_dismantle_consumable.jpg` - before/after: a stack of canned food disposed, the cans returned for the whole stack at once.
